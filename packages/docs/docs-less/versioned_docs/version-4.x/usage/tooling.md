## Recommended Paths

### Team and CI pipelines

Use [Server-side Usage](./using-less) with Node-based compilation in build pipelines.

### Local development convenience

Use [Browser Usage](./using-less-in-the-browser) for rapid iteration, then move to precompile before production.

### Runtime theming scenarios

Prefer browser usage only when live variable/theme customization is a first-class feature.

If you are planning a phased upgrade, keep these tooling choices stable while you evaluate the Less 5.x (Jess-powered) track.
