### [jsDelivr CDN](https://cdn.jsdelivr.net/npm/less@4/dist/less.min.js)

```html
<script src="https://cdn.jsdelivr.net/npm/less@4/dist/less.min.js"></script>
```

For legacy 4.x browser-runtime testing, pin a specific patch version:

```html
<script src="https://cdn.jsdelivr.net/npm/less@4.2.2/dist/less.min.js"></script>
```
