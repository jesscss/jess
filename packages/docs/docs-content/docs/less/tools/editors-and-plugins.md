## Editors and IDEs

| Editor / IDE | Notes |
|---|---|
| [VS Code](https://code.visualstudio.com/docs/languages/css) | Official CSS docs include Less support and current extension ecosystem guidance. |
| [WebStorm / JetBrains IDEs](https://www.jetbrains.com/help/webstorm/transpiling-sass-less-and-scss-to-css.html) | Official Less transpilation workflow for JetBrains IDEs. |

| [Vim](https://github.com/groenewege/vim-less) | Less syntax support for Vim. |
| [Emacs](https://github.com/purcell/less-css-mode) | Less major mode for Emacs. |
