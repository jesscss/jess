Less means **L**eaner **S**tyle **S**heets.

It is CSS with superpowers: familiar syntax, better reuse, and smarter organization for real-world codebases. You keep writing styles the way you already do, but with variables, mixins, nesting, functions, and tooling that scale.

:::info Why teams still pick Less
- **Incremental adoption**: start with plain CSS and add features where they help.
- **Backwards compatible output**: predictable CSS for production pipelines.
- **Built for large stylesheets**: structure design tokens, utilities, and components without fighting your tooling.
- **Clear upgrade runway**: when you are ready, Less 5.x lets teams migrate seamlessly to the Jess language without rewriting everything at once.
:::
