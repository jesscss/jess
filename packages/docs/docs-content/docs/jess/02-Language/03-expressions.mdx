Expressions let Jess evaluate values explicitly.

Write an expression as `$(`...`)`.

- `$var` is a variable `Reference` (not an `Expression`).
- `$(...)` is an `Expression`.

Inside an expression, keep variable references explicit: `$($var)`.

## Examples

### Basic arithmetic

```less
value: $(1 + 2); // 3
value: $(1 - 2); // -1
value: $(1 * 2); // 2
value: $(1 / 2); // 0.5
value: $(1 % 2); // 1 (modulus)
```

### CSS values

```less
value: $(#222 / 2); // #111
```

### Jess variables

```less
$width: 10px;
$height: $($width + 10px);

#header {
  width: $width;
  height: $height;
}
```

## References vs expressions

Inside an expression, a plain identifier is a value or keyword. A variable still
uses its `$` sigil.

```less
$color: red;
value: $(red); // red (color keyword literal)
value: $($color); // red (variable reference inside Expression)
value: $less.iscolor($color); // true
```

```less
$num: 10;
value: $($num + 1); // 11
```

## Arithmetic is explicit

Keep arithmetic inside the expression wrapper:

```less
$w: 10px;
width: $($w + 1px);
```

Use a variable reference inside the expression. Do not write unwrapped arithmetic
such as `$w + 1px`.

## Units

An expression computes with units. Multiplying or dividing by a unitless
number keeps the unit, compatible units convert, and like units cancel:

```less
value: $(2px * 3);         // 6px
value: $(1cm + 10mm);      // 2cm
value: $(2px / 1px);       // 2
value: $(1px * 1px / 1px); // 1px
```

Mixing units is an error by default. Adding a unitless number to a dimension
(`$(1 + 2px)`), adding units that do not convert (`$(1px + 3em)`), and a result
whose unit CSS cannot express — an area such as `$(1px * 2px)` or a reciprocal
such as `$(1 / 2px)` — each stop the compile with `eval/invalid-unit-arithmetic`
at the operation that mixed them. Give both operands the unit you mean
(`$(1px + 2px)`), or write `calc(1px + 3em)` when the browser should resolve it.

The `unitMode` compile option changes that default, exactly as it does for
Less: `preserve` keeps the expression as written and warns
(`eval/unexpressible-unit`), and `loose` computes Less 4.x's answer
(`$(1 + 2px)` is `3px`, `$(1px + 3em)` is `4px`). Without the option, `.jess`
uses `strict`.
