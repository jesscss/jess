id: js
title: JS-in-CSS
---

You can easily import and evaluate JS/TS at compile-time using `@-use` for Sass-module-style namespace imports or `@-from` for ESM-style imports. This allows you to share things like design tokens between JS and CSS.

For example:

```css
@-use './tokens.ts';

.box {
  width: tokens.boxWidth;
}
```
This would produce:
```css
.box {
  width: 2px;
}
```

Use `@-from` when you want ESM-style imports, including named exports:

```css
@-from './tokens.ts' import (boxWidth);

.box {
  width: boxWidth;
}
```

Or a namespace import:

```css
@-from './tokens.ts' import * as tokens;

.box {
  width: tokens.boxWidth;
}
```
