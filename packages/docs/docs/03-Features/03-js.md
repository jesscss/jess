title: JS-in-CSS
---

You can easily import and evaluate JS/TS at compile-time using the `@-use` at-rule. This allows you to share things like design tokens between JS and CSS.

For example:

```css
@-use './tokens.ts';

.box {
  width: tokens.boxWidth;
}
```
This would produce:
```css
.box {
  width: 2px;
}
```
