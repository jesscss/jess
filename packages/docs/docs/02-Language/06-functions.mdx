---
title: Functions
---

:::info

This section refers to functions defined in stylesheets. For importing functions from other languages, see [the `@-use` at-rule](./atrules#-use).

:::

In Jess, functions have a very similar signature to mixins, but are assigned a return value with `:`. The return value is then assigned with `return`.

```less
// Define a function
my-function() : {
  return: #(1 + 2);
}

// Call a function
value: my-function(); // 3
```
