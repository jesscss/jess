## UI/Theme Frameworks and Components
| | |
|---|---|
| [Ant Design](https://github.com/ant-design/ant-design/) | Widely-used React UI system that still uses Less tokens/styles in its ecosystem. |
| [Bootstrap 3](https://getbootstrap.com/docs/3.4/) | Classic Bootstrap generation that ships Less source. |
| [Fomantic UI](https://fomantic-ui.com/) | Active Semantic UI community fork with Less-based theming. |
| [UIkit 2](https://getuikit.com/v2/) | Legacy UIkit release line with Less sources. |
| [React Suite](https://rsuitejs.com/) | React component suite with preprocessor-friendly themes, including Less flows. |

## Build Tool Integrations
| | |
|---|---|
| [webpack less-loader](https://webpack.js.org/loaders/less-loader/) | Official webpack loader for compiling Less. |
| [Vite CSS preprocessor options](https://vite.dev/config/shared-options.html#css-preprocessoroptions) | Configure Less under `css.preprocessorOptions`. |
| [Angular component styling](https://angular.dev/guide/components/styling) | Angular supports Less for component styles and global styles. |
| [Svelte preprocess](https://raw.githubusercontent.com/sveltejs/svelte-preprocess/main/docs/preprocessing.md) | Less preprocessing before Svelte compile. |
