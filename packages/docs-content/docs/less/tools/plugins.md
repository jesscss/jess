| Plugin | Purpose |
|---|---|
| [less-plugin-clean-css](https://github.com/less/less-plugin-clean-css) | Minification during Less compilation. |
| [less-plugin-autoprefix](https://github.com/less/less-plugin-autoprefix) | Vendor-prefix postprocessing in Less workflows. |
| [less-plugin-npm-import](https://github.com/less/less-plugin-npm-import) | Import resolution from npm package roots. |
