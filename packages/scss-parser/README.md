# Jess - SCSS parser

Parser for Sass+

Meaning: not all Sass/SCSS features may be _supported_, and may be evaluated differently or have no output, but they should parse.

## Status

This is currently **legacy/experimental** and not maintained as part of the current Jess compiler path.
It is intentionally kept as a placeholder so older packages can keep depending on it.

Prefer using `jess`’s `Compiler` and the maintained parsers (`@jesscss/css-parser`, `@jesscss/less-parser`).
